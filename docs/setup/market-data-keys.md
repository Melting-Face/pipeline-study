# 시장 데이터 API 키 발급

주식예측 파이프라인(`defs/polygon_market`·`defs/fred_calendar`)이 쓰는 외부 원천의
**키 발급 절차와 제약**이다. 절차 전체의 흐름은 [`../setup.md`](../setup.md) §6-2에 있고,
이 문서는 그 세부와 **무엇이 보증되지 않는지**를 갖는다.

## 왜 이 원천들인가

| 원천 | 상태 | 이유 |
| --- | --- | --- |
| Polygon.io | 채택 | 하루치 전 미국 티커를 **한 번의 호출**로 준다 → 일자 파티션과 1:1로 맞고, 그날 거래된 종목 전체가 응답이라 별도 유니버스 자산 없이 생존 편향이 해소된다 |
| FRED | 채택 | 연준 공식·무료. ALFRED vintage(`realtime_start`)가 있어 **발표 시점 기준 값**을 되살릴 수 있다 — 예측 파이프라인의 누수 방지가 여기에 걸린다 |
| SEC EDGAR | 폴백 | 미국 정부 저작물이라 키가 필요 없다. 뉴스 축이 거부될 때만 쓴다 |
| Investing.com | 제외 | 약관이 사전 서면 허가 없는 **데이터 저장·복제·배포를 금지**한다. 레이크하우스 적재가 곧 저장이다 |

## 발급 절차

1. **Polygon.io** — 계정을 만들면 무료 플랜의 키가 대시보드에 바로 나온다.
   `polygon.io`가 `massive.com`으로 리다이렉트될 수 있다(리브랜딩 중). API 호스트는
   `api.polygon.io`로 유지된다.
2. **FRED** — 연준 계정을 만든 뒤 API Keys 페이지에서 즉시 발급된다.
3. 두 값을 `.env`에 채운다([`../setup.md`](../setup.md) §2).
4. in-cluster로 쓰려면 Secret 배선도 함께 본다 — `.env`만 고치면
   **로컬에서는 되고 클러스터에서만 조용히 실패**한다. 전파 체인의 정본은
   [`../operations.md`](../operations.md) §1이다.
5. `uv run scripts/stock_source_access_probe.py --source all`로 판정한다.
   종료코드 `0`이어야 자산을 켠다. `2`(판정 불가)를 통과로도 거부로도 읽지 않는다.

## 인증 방식이 코드를 가른다

Polygon은 `Authorization: Bearer` 헤더를 지원해 키가 URL에 실리지 않는다. FRED는 `?api_key=`
쿼리 파라미터뿐이라 **예외 메시지에 전체 URL이 새어나갈 수 있고**, `common/helper.py`의
`_request`가 그런 API에 `fetch_json`을 그대로 쓰지 말라고 금지로 적어 뒀다. 그래서 FRED만
`common/fred.py`가 `raise_masked()`로 감싼다. 새 원천을 붙일 때 **이 축을 먼저 본다.**

## 무료 플랜의 한계가 곧 파이프라인의 한계다

Polygon 무료 플랜은 분당 호출 수·조회 가능한 과거 범위·데이터 신선도에 제한이 있다.
**이 값들은 벤더가 바꾸므로 여기 적지 않는다** — 가격 페이지를 직접 확인하고, 실효 경계는
프로브가 잰다.

- 프로브가 출력하는 **"조회 가능한 가장 오래된 날짜"** 가 데이터셋 `constants.py`의
  파티션 시작일을 정한다. 문서의 숫자를 믿고 잡으면 백필이 조용히 빈 파티션을 만든다.
- 파티션당 요청이 1건이므로 **분당 호출 수가 그대로 백필 속도**다. 대량 백필 전에
  Dagster `max_concurrent_runs`와 함께 본다([`../resource-sizing.md`](../resource-sizing.md)).

## 재배포 금지

두 원천 모두 **원본 데이터를 재배포할 수 없다**(Polygon 무료 플랜은 개인 사용 한정).
적재된 Iceberg 테이블·노트북 셀 출력·리포트에 담긴 원천 값 어느 것도 저장소나 외부로
내보내지 않는다. 공개하는 것은 코드와 조회 시점뿐이다. 같은 이유로 **기사 본문을 적재하지
않는다** — 제목·링크·발행시각·티커 메타데이터만 담는다. 판정 정본은
[`../security.md`](../security.md).

## 뉴스 축이 거부되면

Polygon 무료 플랜에 뉴스가 포함되는지는 **가격 페이지가 명시하지 않는다**. 프로브가
`--source news`에서 `1`(거부)을 내면 SEC EDGAR Atom으로 바꾼다.

- SEC는 키가 필요 없는 대신 **연락처를 포함한 User-Agent를 정책으로 요구**한다.
  없으면 403이고, 넣으면 통과한다. 값은 `NEWS_RSS_USER_AGENT`에 둔다(개인 연락처라
  코드에 박지 않는다).
- 이 폴백은 **자동이 아니다.** 서브프로젝트 이름과 스키마가 함께 바뀌고, 피처의 성격이
  "뉴스 헤드라인"에서 "공시 이벤트"로 바뀐다. 프로브 결과를 보고 사람이 판단한다.

## 접근이 되는 것과 쓸 수 있는 것은 다른 축이다

원천을 고를 때 **HTTP 응답이 오는지**만 보면 안 된다. 이 파이프라인은 뉴스의 발행시각을
거래 세션 경계에 배정해 누수를 막는데, 그 설계는 **기사마다 다른 발행시각**이 있어야 성립한다.

접근이 되고 형식도 맞는데 피드의 모든 항목이 **같은 시각**(= 피드 생성 시각)을 갖는 원천이
실재한다. 그런 원천을 쓰면 모든 기사가 같은 거래일에 배정되고, 피처는 만들어지고, 모델도
학습되고, **어디서도 에러가 나지 않은 채 결과만 틀린다.** 그래서 프로브는 200을 성공으로
읽지 않고 **발행시각의 분산**까지 본다. 원천을 바꿀 때 이 검사를 함께 옮긴다.
